VibeCoderz: describe an app, watch it get built

An end-to-end, browser-based vibe-coding platform — you describe what you want in natural language, and it generates the app in front of you, with a live preview, a file explorer, and streaming build logs, all in one screen. Open-source in spirit: the whole loop from prompt to running preview, visible the whole way.

VibeCoderz is a browser-based platform for building software by describing it. You type what you want, the system generates it, and you watch the result take shape in a live preview — with the generated files and the build logs open next to it, so the process is transparent rather than a black box that spits out a zip file.

The problem

"Vibe coding" — building software by describing intent to an AI rather than writing every line — went from a joke to a real workflow fast. But most tools that do it hide the machinery: you get an output, not an understanding, and when something's wrong you're stuck because you can't see what the model actually did. The gap isn't generation quality; it's visibility and control over a process that's otherwise opaque.

The approach

VibeCoderz puts the whole loop on one screen. The verified interface brings together:

  • A chat panel — where you describe the app or the change you want, in plain language.
  • A live preview — the running result, updating as the build proceeds.
  • A file explorer — the actual generated source, not just the output, so you can see and edit what was produced.
  • Streaming build logs — the process as it happens, so a failure is legible instead of mysterious.

Design principle: the point of putting files and logs beside the preview is that a build you can inspect is a build you can trust and fix — the tool should make you more capable, not just hand you an artifact you can't reason about.

Status

The platform has a working interface — chat, preview, file explorer, and logs are all in place.
